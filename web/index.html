Źródła dodatkowe

          
          
          
          

            

          
Baza (ok. 108 MB) pobiera się RAZ i siedzi w Cache jako
            indeks; przy szukaniu grafik nie ma już żadnych zapytań do sieci — pobierana
            jest dopiero wybrana grafika. Odśwież co jakiś czas, żeby mieć nowe pozycje.

          
          
          
          

            
            

          
EmuMovies nie ma publicznego API — dostęp dla abonentów
            idzie przez FTPS (files2.emumovies.com), a biblioteka jest tam w PACZKACH
            (setki MB każda). Paczek nie pobieramy: ze spisu treści ZIP-a bierzemy
            pojedynczą grafikę. Spis robimy raz, potem wszystko idzie z dysku.
            Paczki RAR/7z (wieloczęściowe) są pomijane — tych nie da się czytać
            bez ściągnięcia całości; po spisie wypiszemy, czego zabrakło.

          
          
          
          
          
          
          

            

          

            
            

          

            

          
          
API wymaga danych dewelopera (devid/devpassword)
            przyznawanych autorowi programu na wniosek — samo konto użytkownika nie wystarcza.
            Konto usera jest opcjonalne i tylko podnosi dobowy limit zapytań.
